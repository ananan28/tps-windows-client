# TPS Windows Client

Windows 独立客户端开发仓库。

## 维护归属

本仓库由 2026-10-03 创建的当前 GPT 对话维护。用户明确要求：其他 GPT 窗口不要修改、提交、合并或触发构建。此备注是协作约定，不是 GitHub 权限锁；用户可以明确转交维护。

## 目标

- 仅 Windows，提供图形界面和可分发的程序包。
- 支持带用户名/密码的 HTTP 代理，代理配置由用户在本机填写。
- 首次验收采用一个线程、可见浏览器、一条用户授权的测试资料。
- 对比人工查询与采集字段，验证 XLSX 导出、停止和失败任务保留。
- 网站要求人工验证时暂停并提示用户，不把验证页判为无结果。
